## 1. 先纠正导致方向摇摆的证据解读

当前混在一起的实际上是三个问题：从零构造整条 tour；在固定 endpoint/downstream policy 下选择 source；对一条已有较好 tour 做受限片段重连。三个问题的负结果不能互相替代。

| 已有证据 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 历史 canonical TSP50 多 host 实验有正收益，AM/PtrNet 跨 seed 证据较强 | 特定联合表示与训练配置值得解释 | 新 source-first 实现一定有效；强 host 普遍受益；收益来自纯 source 选择 |
| 新 source-first TSP100：ASCC+RL 比 route 差 10.616%，ASCC+BOPO 差 14.508% | 当前接入与小预算训练没有兑现优势 | ASCC 充分训练也必然失败；BOPO 在所有设置下更差 |
| TSP50 固定 downstream 的 source rollout oracle 约 +0.84%，学习选择器未达到正收益 | 该 checkpoint 和干预位置存在有价值的 source 选择 | 它是 ASCC 的全局性能上限；已经有可部署的 0.84% 提升 |
| 较好 tour 切成 4/8/12 段后的精确重连增益很小 | 这些切法、这些 seed tours、这个冻结内部边邻域空间有限 | 从零森林构造的空间有限；一般 destruction 不重要；训练不是瓶颈 |

依据：[历史审阅](RESEARCH_ROOT/audit_20260919/Research_Audit.md:138)、[source-first 筛查与训练量](RESEARCH_ROOT/implementation_20260919/RESEARCH_PROGRESS.md:1)、[rollout oracle 与失败学习器](RESEARCH_ROOT/implementation_20260919/ROLLOUT_VALUE_EXPERIMENT.md:1)、[片段重连诊断](RESEARCH_ROOT/implementation_20260919/FRAGMENT_RECONNECTION_EXPERIMENT.md:1)。本表用于区分证据性质，不构成同设置性能排行榜。

**上一轮片段报告的两处推断应收回。** “destruction 选择不是主要瓶颈”和“即使完美训练当前动作空间，收益也太小”超出了实验范围。代码要求所有片段长度至少为 2；随机切法先给每段两个节点，再以 multinomial 分配剩余节点，偏向较均衡的段长；最长边切法也禁止相邻切边。因此没有覆盖单节点释放、局部密集破坏、一般不均匀切法。64 组只是这个采样分布下的候选集合，不是所有 destruction 的 oracle。[切分代码](RESEARCH_ROOT/implementation_20260919/experiments/evaluate_fragment_reconnection.py:76)

冻结 checkpoint 在这些森林上的失败还包含分布迁移；不能拿它代替针对这些状态训练过的 repair 模型。相反，从全体孤立节点开始的完整图 ASCC 可以生成每个 Hamiltonian tour，并不受上述小修复邻域限制。

同样需要保留的事实是：新实现仅训练 200 steps、800 个实例，ASCC 最佳 checkpoint 均在末步，尚未充分收敛；旧 route 预训练并不等于 forest endpoint 预训练。历史 AM 已有 trained-random 对照，但新 source-first 强 host 尚未完成，不能笼统说整个项目“没有 random 实验”，也不能把旧实现的结论移植过来。[训练与消融边界](RESEARCH_ROOT/implementation_20260919/RESEARCH_PROGRESS.md:1)

## 3. 最接近的三项工作如何改变决策

**L2C-Insert：自由度需要完整状态信息和相应训练。** 它主要学习“插在哪里”，选哪个节点使用 nearest-neighbor；其附录做了真正分别训练的 random/nearest 对照，并明确把 learned node selection 写为未来工作。只加一个选节点网络是自然增量，需更强机制或效果支撑。此外其 unvisited-node 输入消融说明：能否看到尚未处理的结构值得优先检查。不能据此断言我们的具体森林模型一定缺哪项特征。[方法与附录 E](https://arxiv.org/html/2505.13904)

**DRHG：与当前 ASCC 有区别，但不是完全不同的领域。** DRHG 在破坏已有解后压缩片段，解码仍依赖 first/current node，并在选中片段一端后强制遍历另一端；当前 ASCC 每步可以选择另一分量的 tail，再选 head。可研究的差别是“串行遍历分量”与“任意分量对合并”的学习与预算表现；双方一般不因这些顺序规则而拥有不同的全部可达 tours。此差别是否有价值需要直接对照，不能仅凭表示名称宣布。[DRHG §3](https://arxiv.org/html/2502.16170)

**Learning to Segment：值得学它的研究方法，不宜直接复刻题目。** 其切入点是观测稳定片段造成重复搜索，通过 look-ahead 数据训练识别器，再报告整个求解过程的收益。论文还讨论 oracle 预测不完美时的表现。因此应模仿“可观测瓶颈→oracle→可学习性→扣除开销后的系统收益”这一证据链；不应把拥有 oracle 空间当作有可发表方法。[L2Seg 方法与假设验证](https://arxiv.org/html/2507.01037)

## 4. 群论应承担什么角色

以下为对当前完整图有向 TSP 状态与 mask 的数学分析，不是文献实验结论。[实际 source/head mask](RESEARCH_ROOT/implementation_20260919/src/groupopt/models/ascc_bopo.py:140)

设 partial permutation 的连通分量是 m 条不相交有向路径，含孤立节点，且 m≥2。每个分量只有一个未指定 successor 的 tail、一个未指定 predecessor 的 head。

1. 任取一个 tail，合法 head 恰是其他 m−1 个分量的 head；不同 source 的合法 endpoint 数相同。
2. 固定方向的全部 Hamiltonian completions 对应分量的有向循环排列，数目为 (m−1)!。
3. 指定任意合法 tail→head 后合并两个分量，剩余 completions 数为 (m−2)!。

因此，source 选择本身不改变候选解集合；assignment 才将其细化。对当前完整图、固定方向、无额外约束的计数而言，每个分支大小一样。**“优先处理合法选择更少的 source”不是这套 TSP mask 下可成立的解释。** 各分支的成本分布、好解质量、神经模型误差仍可能差很多；这些才是需要学习和测量的对象。

稳定子链/陪集可以准确描述部分置换约束。但该解释没有自动产生比一般变量赋值更强的算法，也没有自动证明更快、更容易训练或更高样本效率。更值得数学合作者投入的是：明确可交换动作及等价历史；定义哪些状态信息足以决定后续优化；分析采样和监督是否不必要地依赖等价历史；研究小规模精确 completion value。是否形成新理论，要与随机顺序和对称性学习文献逐项比较。

注意：端点编号重排的置换等变性、同一解的构造顺序等价性、对称 TSP 的整体反向等价性，是不同对象。不能统一称为“群不变性”后混用。反向一条已经赋值的有向路径会撤销其 successor constraints；split/repair 同样重置部分约束，不能继续宣称沿原有单调稳定子链构造。

## 5. 唯一建议立即推进的验证主线

**研究问题：用森林状态匹配的 endpoint 训练消除接入失配后，learned source 能否在同等预算下优于 random、固定顺序和简单启发式？**

这是值得验证的假设，不是当前已证明的贡献。暂时不提出新算法名称。

**第一步：建立可解释的森林训练基线。**

- 用同一批较好完整 tours 生成不同 source 顺序的合法 partial forests；从 singleton-rich 到多段状态都覆盖，不限制每段长度≥2。
- 给定 source，用目标 tour 的 successor 监督 endpoint，先验证 endpoint 在新状态分布上是否学得会。这只教会“如何在多种顺序下完成好解”，不能教会“哪个 source 最优”。
- 检查模型是否需要知道其他分量的 head、tail、内部成员关系等动态信息。若修改状态编码，所有用于隔离 source 的 forest arms 使用同一编码；另设增强 route 对照，避免把状态编码收益记给自由顺序。
- 保留不做 forest warmup 的对照。若只有 warmup 有效，应将贡献解释为训练适配，不能先记作 adaptive ordering。
- 此处不把随机 teacher trajectory 的下一个 source 当成唯一正确标签。也不声称现有 REINFORCE 因此数学上错误：它优化的是期望终局成本，等价轨迹本身不使估计有偏。

**第二步：真正重训 source 消融。**

| Arm | 构造机制 | 隔离的问题 |
|---|---|---|
| Native route | 已复现的强 route checkpoint/训练配置 | 实际起点与上游基准 |
| Enhanced route / route-capacity | 固定续接，启用对等有效容量与信息 | 排除加参数、加状态信息收益 |
| Fixed-source forest | 固定 unresolved source 规则，endpoint 正式训练 | 任意顺序是否必须 adaptive |
| Random-source forest | 训练和测试都随机选 source | 森林表示与随机顺序本身的效果 |
| Heuristic-source forest | 预先选定一个简单规则并相应训练 | 学习策略能否超过廉价 ordering |
| Learned-source forest | source+endpoint 联合训练 | adaptive learning 的增量 |

所有 arms 明确初始化、teacher 数据、样本数、轨迹数、超参搜索次数。先做 3 个配对训练 seeds 的筛查；通过后冻结方案，再做至少 5 seeds 和全新 test。随机 source 的 action seeds 与训练 seeds 分开。不能以更多 starts 给 learned 模式隐性预算，也不能只对 ASCC 加训。

记录双口径：相同训练样本预算的质量，以及包含监督数据生成/预热成本的训练时间曲线；推理同时给相同 rollout 数和相同时间。预先限定训练总预算及 validation checkpoint 选择规则，避免某组没有收敛就被判失败；若预算内仍无信号，只作投入决策，不作“所有 ASCC 永远无效”的结论。

**第三步：只有 source 确实有增量才开发更复杂训练方法。**

优先考虑 source 与 endpoint 的信用分配：在同一个森林状态下，以同一后续策略评估不同 source 的终局收益；训练共享的组件交互模型，预测相对基准动作的收益，并补足模型实际访问的 states。已有独立 candidate MLP/树模型失败不能证明全局信息模型也失败，但也不支持立即无限制扩大模型。

如果要做多正例/等价历史训练，必须与随机顺序监督、普通 REINFORCE、MACSIM 风格 set loss 分开比较。所有目标 tour 上可行的下一条边都是“能恢复该 tour”的正例；这不意味着它们对不完美 downstream policy 的长期价值相等。**解决标签冗余和学习最优决策顺序是两个问题。**

## 6. 继续与停止的门槛

| 结果 | 正确解释 | 投入决定 |
|---|---|---|
| 森林训练明显修复迁移退化，但未超 route | 原强 host 接入存在学习/状态失配 | 不称方法优势；在预设预算内完成消融后决策 |
| Random/fixed forest 超过 route，learned 没有进一步改善 | 森林表示/训练或随机化更重要 | 收缩“学习顺序”主张；评估这种机制是否还有足够新意 |
| Learned 超过 random/fixed，但不超过 heuristic | 部分学到了 ordering，未超廉价规则 | 不以 learned adaptive ordering 为主贡献 |
| Learned 在等时间下稳定超过增强 route 和最佳简单 ordering | 有独立、可部署的顺序收益 | 扩第二种构造机制/强模型，进入论文主实验 |
| 增益只在多算 rollout 或更多训练时出现 | 当前更像计算预算效应 | 不进入规模扩展；先解决效率，否则停止主线 |
| 完成适配和预设预算后，各森林模型仍明显落后 | 当前路线的投入回报不足 | 停止将它作为本轮 ICLR 投稿主线；保存负结果与诊断 |

不预设“超过 0.5% 就可投稿”。应根据方差、基准 gap、计算成本、跨 seed 稳定性和新颖性判断。统计显著不等于研究重要；几个样本上的大 oracle 收益也不等于学习算法有效。

## 7. TSP 规模与其他 Routing 的顺序

**当前用 TSP50/100 回答学习问题。** 小规模便于获得高质量参考解、做配对干预与少量精确 completion 标签。它们是诊断台，不足以单独支撑“通用强 Routing solver”。

**通过门槛后先做 TSP200，再做 500/1000。** 预先指定 uniform、clustered、非均匀密度及 TSPLIB 类外分布，不按结果选择展示。已有 200/500/1000 迁移失败是旧小预算 checkpoint 的开发证据，不能反复拿来作最终 test。

大规模是否更适合取决于机制：若收益来自压缩、并行决策或减少重复编码，应展示随 n 增长的时间/显存优势；当前逐边 tail/head 决策并不会因“多路径”自动并行，压缩与联合 logits 也各有近邻工作。若只来自更好的顺序，n 变大可能同样放大学习和误差累积难度。

**CVRP/CVRPTW 放在机制明确以后。** 如果实验证据支持“剩余约束差异引导顺序”，可优先选择紧度可控的小型 CVRPTW，系统改变容量和时间窗，观察合法选项不均匀程度与收益关系。只加入容量 constraint 并不保证机会更大，time-window mask 也不自动保证全局可完成；需要明确 infeasibility 处理与理论边界。[紧度研究](https://arxiv.org/abs/2505.24627)

暂不同时扩 ATSP、CVRP、VRPTW、PDP。ATSP 能检验有向表示和非几何成本，但完整 ATSP 仍有相同的合法候选计数，不能用来单独验证“少域变量优先”的机制。

## 8. 如果目标是 ICLR，论文还需要什么

保守的候选贡献应是：

> 识别多片段神经构造中的具体学习障碍，提出可解释的状态表示或训练方法，并通过严格顺序消融证明其在给定预算下的独立收益及适用边界。

“采用群论解释 + 多个模型小幅改善”目前不够；“换一个 loss + 添加 source head”也不自动构成足够方法贡献。需要先由实验确定障碍是状态分布、动态结构信息、信用分配，还是该自由度价值本来就有限。

建议论文证据包包含五张主图：

1. **训练曲线**：route / random / learned，横轴分别为训练样本和累计 GPU 时间，区分 warmup 与联合训练。
2. **机制消融图**：顺序策略 × 是否森林适配，展示每个训练 seed 与配对差异区间。
3. **质量—推理时间曲线**：同设备、相同实例，比较更大 multi-start、插入构造与模型本身，计入预处理。
4. **oracle→可学习→部署收益图**：oracle 明确标成使用未来信息的诊断，不能把其运行时间当实际算法性能。
5. **边界热图**：规模/分布或约束紧度；保留失败单元格，最终 test 不参与路线选择。

对于从零构造，L2C-Insert 是重要结构对照；若以后改做片段修复，DRHG 必须直接比较；若改做识别并压缩稳定片段，必须比较 L2Seg。最终质量还需 Concorde/高质量 LKH 参考；若参考未证明最优，写 reference/BKS gap，不能写 OPT gap。BOPO 是可选训练对照，不再当作必须超越的唯一对象。

当前最值得做的不是继续寻找一个能让 ASCC 看起来有利的数据集，而是完成这一轮尚未完成、能区分假设的训练验证。通过则投入；未通过则停止这条投稿主线。已有审阅、负结果与实现检查都能保留为后续研究资产。
