# Measuring State Aliasing in Neural Multi-Fragment Routing

This research package distinguishes exact fixed-source diagnostics, controlled
neural prediction, limited official-backbone adaptation, and historical evidence.
It does not claim a state-of-the-art routing solver or an advantage from learned
source order. Read the protocols before interpreting the results.

## Contents

- `paper/main.tex`: anonymous manuscript using the official ICLR 2027 style.
- `verify_witness_interval.py`: standard-library numerical certificate for the
  seven-point observation-aliasing witness.
- `counterfactual_stress.py` and `counterfactual_stress/`: 1,536 newly sampled
  larger-instance counterfactual pairs, exact completion labels and summaries.
- `exact_diagnostic/`: matched neural controls, exact Bayes-risk evaluation,
  shuffled association controls, small-scale heuristics and raw outputs.
- `state_adapter/`: two official routing backbones, route/random construction,
  blind/aware component state, frozen and decoder-adapted experiments.
- `historical_recomputed/`: independent recomputation from archived cost vectors.
- `verify_artifacts.py`: independent numerical artifact checks.
- `PROTOCOL.md`: initial scope and interpretation rules. Experiment-specific
  protocols record subsequent amendments and supplementary controls.

## Run the self-contained diagnostics

From the directory containing `iclr_20260919/`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r iclr_20260919/requirements.txt
python iclr_20260919/verify_witness_interval.py
python iclr_20260919/counterfactual_stress.py
python iclr_20260919/recompute_historical.py
python iclr_20260919/build_paper_assets.py
python iclr_20260919/verify_artifacts.py
```

The interval certificate does not require NumPy or PyTorch. The larger stress
test uses CPU NumPy. Coordinates and exact labels are included, allowing checks
without training. Neural conditional experiments use CUDA; see that directory's
results report for the full command sequence. Recorded training versions are
authoritative; the requirements above are broad compatibility ranges, not a
claim of bitwise identity across hardware or library versions.

## Official backbones

Backbone checkpoints and upstream repositories are external dependencies, not
included here. `state_adapter/README.md` gives their expected layout. Set
`GROUP_OPT_ROOT` to that layout. The Attention Model implementation is from
[its official repository](https://github.com/wouterkool/attention-learn-to-route).
The ICAM source and checkpoint must match the checksum recorded in each suite's
configuration; use the source linked by the [ICAM paper](https://arxiv.org/abs/2405.01906).
Selected residual/decoder checkpoints and per-instance evaluation costs are
included. Large cached encoder tensors are regenerated by the preparation step.

## Statistical and scientific scope

Coordinate geometries, not paired forests, are independent statistical units.
Conditional neural comparisons use three independently initialized training
seeds with common data. Historical joint seeds share warmup and must not be
treated as three fully independent end-to-end runs. A fixed-source Bayes lower
bound is not a lower bound for a joint source policy or a complete TSP solver.
The full tail-by-head legality matrix can reveal component pairing; the audited
endpoint interface sees only its selected-source row.

The component-state intervention supplies several dynamic features. Its
full-tour effect cannot be attributed solely to target endpoint pairing.
Decoder-only adaptation still freezes the encoder. Learning curves, all failed
or negative comparisons, source randomness, and timing scope are retained.
